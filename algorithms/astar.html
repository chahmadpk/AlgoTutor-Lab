A* Search Algorithm

Overview

A* is a graph traversal and path search algorithm, which is used in many fields of computer science due to its completeness, optimality, and optimal efficiency.

The Formula

A* uses f(n) = g(n) + h(n)

  • g(n): The cost of the path from the start node to n.
  • h(n): A heuristic that estimates the cost of the cheapest path from n to the goal.

Complexity

Time Complexity: O(E) in the best case, but can be O(b^d) where b is the branching factor.
