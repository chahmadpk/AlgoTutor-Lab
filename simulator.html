Understanding Editor Modes

🧱 Obstacle Mode

These are like walls or closed doors. The computer cannot walk through them and must find a way around.

⚖️ Cost Mode

These are like muddy paths. The computer can walk through them, but it's slower and harder. It will try to find a clean path if it can.

🌀 Hybrid Mode

A mix of walls and mud! Use this to build your own complex maze and test the computer's brain.
