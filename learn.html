Deep Dive

Core Concepts

What is Pathfinding?

Pathfinding is the plotting, by a computer application, of the shortest route between two points. It is a more practical variant on solving a maze.

Heuristics (A* & Greedy)

In A* and Greedy Search, a heuristic is a function that estimates the cost of the cheapest path from the current node to the goal. A common one is the Manhattan Distance.
